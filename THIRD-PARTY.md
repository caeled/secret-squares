## Project Nayuki QR Code generator

Source: https://github.com/nayuki/QR-Code-generator

Bundled source: typescript-javascript/qrcodegen.ts, source blob c4191ac0b5f8a24d87fd9340ceaa2d3b07d0231a. MIT, copyright Project Nayuki. Full notice is retained in both vendor/qrcodegen.ts and vendor/qrcodegen.js. The JavaScript is mechanically transformed from TypeScript using Node.js 24 stripTypeScriptTypes transform mode; the original license header is preserved. No algorithm changes. The workshop constructs a separate scratch instance to inspect the encoder’s reserved function-module map, without changing output symbols.
